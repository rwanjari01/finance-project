# FinTrack Personal Finance Management System

## Run
1. Open this folder in VS Code.
2. In terminal:
   python -m pip install -r requirements.txt
3. Run:
   python app.py
4. Open http://127.0.0.1:5000

Features:
- Signup/login with hashed passwords
- SQLite database
- Dashboard with balance, income, expenses and savings
- Income/expense CRUD
- Charts using Chart.js
- Monthly budgets with spending progress
- Financial goals with progress updates
- Responsive UI

For a college demo this is fully functional locally. Before production deployment, change the Flask secret key and use a production server.
